GLSL effects rendered on the GPU. Applied by intent through `add_video_effect`:

```json
{ "tool": "add_video_effect",
  "input": { "clipId": "clip-1", "effectType": "vhs",
             "params": { "intensity": 0.8 } } }
```

The tool resolves the name, fills in every unspecified parameter, and stores the clip effect as `{ type: "shader", params: { shaderId, … } }`. Unknown names are refused with `UNSUPPORTED_EFFECT`.

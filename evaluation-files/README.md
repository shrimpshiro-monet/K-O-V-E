# evaluation-files/

Evaluation inputs, synthetic fixtures, and result summaries for the K.O.V.E
AI director (Monet).

## Rules

1. **Never commit real or user video files.** Media live in
   `evaluation-files/media/` locally and are gitignored. Only small
   JSON/Markdown results and manifests are committed.
2. **Synthetic media is labeled.** Everything generated by
   `pnpm eval:media:synthetic` carries a red border in-frame and is marked
   SYNTHETIC in `projects.json`. Synthetic clips test pipeline plumbing
   (ffprobe metadata, frame sampling, scene cuts, `plan_edit` end-to-end
   with a mock LLM) and say nothing about edit quality.
3. **Live runs are OWNER-RUN.** They read media and provider keys from the
   owner's local machine and write only compact JSON/Markdown summaries
   (`baseline-*.json`, `eval-live-*.json` are gitignored).

## Layout

| Path | Contents | Committed? |
|---|---|---|
| `projects.json` | Corpus manifest: 9 projects × 3 prompt types (detailed/vague/genre), 5 categories (game, multi, speech, sport, stream). The baseline harness expects exactly this shape. | yes |
| `media/` | Corpus media, generated or owner-supplied. | **no** (gitignored) |
| `INVENTORY.md` | Media/fixture inventory with provenance flags. | yes |
| `baseline-*.json` | Baseline harness reports (generated). | **no** |
| `eval-live-*.json` | Live model-comparison reports (generated). | **no** |
| `blind-test/` | Blind A/B harness outputs (owner-run, see §8 of the fix plan). | **no** (summaries only, if committed) |

## Generating the synthetic corpus (sandbox / CI)

```bash
# requires ffmpeg on PATH (CI ubuntu images have it; `pnpm dev` machines too)
pnpm eval:media:synthetic
```

Regenerates `media/` (14 synthetic clips + `music-bed.wav`) from the
generator script; `projects.json` is rewritten deterministically.

## Running the baseline in this environment

```bash
# scripted/mock corpus tests (no keys, no network)
pnpm --filter @kove-advanced/agent test:run

# live Workers AI baseline (needs credentials in .dev.vars or env):
# KOVE_EVAL_BASELINE=1 pnpm --filter @kove-advanced/agent test:run src/eval/baseline.test.ts
```

Credential precedence (see `packages/agent/src/eval/baseline.ts`):
`KOVE_EVAL_CLOUDFLARE_*` env → generic `CLOUDFLARE_*` env → `.dev.vars`.
`.dev.vars` is gitignored and must never be committed.

## Owner: live runs with real footage

Put your real corpus in a local directory (same `projects.json` shape as
here — 9 projects, one prompt of each type, media relative to that
directory), then:

```bash
pnpm eval:live --models <model-a>,<model-b> --media /path/to/local/media-dir
```

See `docs/AGENT-CAPABILITIES.md` for tool surface and the fix-plan §8 notes
for the comparison-table format. Results are written to this folder as
small JSON + a Markdown summary; commit only those summaries if you want
them tracked.

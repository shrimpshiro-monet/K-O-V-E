# K.O.V.E — Media & Fixtures Inventory

Generated 2026-10-18 (sandbox). Per §0.5 of the master fix plan: every file
that is media (video/audio/image used by pipelines or tests), with path, size,
duration/resolution/codec (ffprobe), provenance (real footage / synthetic /
LFS pointer / UI asset), and whether it carries speech, music, or scene cuts.

**Headline findings**

1. **No real footage exists in this clone.** `evaluation-files/`, `audio/` and
   `reference/` were absent; the upstream history of this repo is a single
   squashed commit (26 MB `.git`), so LFS pointers and earlier media cannot be
   audited from here. The original upstream repo (`Augani/kove-advanced-video`)
   is not reachable from this sandbox (`Repository not found`).
2. **All evaluation video is now synthetic** (generated 2026-10-18 with
   ffmpeg `color`/`testsrc`/`sine` sources, red border = in-frame synthetic
   marker). It exercises ffprobe metadata, frame sampling, scene-boundary
   detection and `plan_edit` plumbing only. It says nothing about edit quality.
3. **One image needs an owner decision:** `apps/web/e2e/fixtures/subject-portrait.jpg`
   is a real photograph of an identifiable person (stock-photo style) used by
   the e2e vision pipeline. See ⚠ rows.
4. Two `creating-views/project/uploads/*.png` files are leftover dev artifacts
   (app UI mockup screenshots) and are candidates for deletion.

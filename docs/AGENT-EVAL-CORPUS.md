# Optional agent evaluation corpus

`evaluation-files/projects.json` and the footage it references are **not in this checkout**. They are a separate, potentially large evaluation dataset; no network download URL or permission is implied. The default agent test run skips only corpus-dependent tests when this manifest is absent and reports that reason. If it exists, missing referenced assets are **test failures**, not skips.

To run the corpus tests locally, obtain the authorized dataset from its maintainer and place `projects.json` and its referenced media/music/reference files under `evaluation-files/` at the repository root, preserving relative paths. `projects.json` must contain nine project objects with IDs including `game-01`, `pod-02` and `multi-03`, categories game/multi/speech/sport/stream, and exactly one prompt each of types `detailed`, `vague` and `genre`. See `packages/agent/src/eval/corpus.ts` for the validated shape. Then run `pnpm --filter @kove-advanced/agent exec vitest run src/eval/corpus.test.ts src/eval/baseline.test.ts` and inspect any asset-gate failures before enabling live baseline runs. Never commit private footage or credentials.

Generated-media render goldens are separate from this corpus. Install `ffmpeg` on `PATH` and Playwright Chromium (`pnpm --filter @kove-advanced/studio exec playwright install chromium`) to enable `effect-goldens.test.ts`. The CI workflow installs both after GitHub Actions billing is restored. An absent ffmpeg executable produces an explicit skipped suite; a present but broken ffmpeg or compositor remains a test failure. These skips are *not* evidence of real-media parity.

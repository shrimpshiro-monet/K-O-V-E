## 1. Executive summary

Kove Advanced is a **browser-native professional-grade editor with an embedded
AI director that no shipping competitor matches**. Its weaknesses are not editing
features — the editing surface is deep — but the unglamorous connective tissue of
professional post-production: interchange with other NLEs, collaborative review,
color management/HDR, and delivery infrastructure (publish, stock, cloud).

- **Strongest card:** the AI director is a *real* edit planner with frame-backed
  evidence, a plan/validate/repair contract, one-shot plan semantics, and refusal
  gates (it refuses to plan a footage edit it has not analyzed). Descript's
  Underlord is conversational editing; Premiere's AI Assistant is a rough-assembly
  beta; nobody else has a director that *proves* it looked at the pixels.
- **Biggest exposure:** zero round-trip interchange. No OTIO, FCPXML, EDL, AAF,
  or XML of any kind. Any user whose pipeline starts or ends in Resolve/Premiere/
  Final Cut/Avid **cannot bring work in or out**. For an editor that calls itself
  professional, this is the #1 gap.
- **Loud correctness defect found during verification:** a WebGL/WebGPU-only
  `shader` effect path with no CPU/2D fallback — renders nothing where WebGPU is
  unavailable (§7.3). Several other E2E "errors" traced to harness bugs, not the
  product (§7.1–7.2).

## 3. Where Kove beats the field

1. **Frame-evidence AI direction.** The planner refuses un-analyzed footage
   (`ANALYSIS_REQUIRED` gate; `FRAME_CAPTURE_FAILED` honest failure) and refuses
   to re-plan after a one-shot plan lands — manual edits keep the AI's hands off
   what the user just fixed (this branch's `TARGETED_EDIT_HINT` work). No other
   editor gates AI output on captured evidence of the actual frames.
2. **Agent depth as product surface.** 323 tools with refusal semantics, mutation
   ledger, approval cards, dry-run mode, fallback provider ladder, and an MCP
   endpoint — Kove is the only NLE you can drive from a terminal/agent, not just
   from its own UI.
3. **Browser-native, zero-install pro stack.** Resolve = free desktop with
   Hollywood-grade color; Kove = zero install with real scopes, ProRes export,
   multicam, nesting, keyframes, proxies. WebCodecs + MediaPipe in-browser.
4. **Mirror/EditDNA.** Reference-driven style imitation (pace/cut rhythm/look/
   structure) with reference media refuses to ever touch the timeline. Unique.
5. **fxpkg.** A distribution format for GPU effects with perf budgets — the
   beginning of an effect ecosystem (Resolve has OFX, Premiere has .mogrt / CEF
   panels; nobody browser-native has this).
6. **Honest failure UX.** Failures surface as errors, not silent no-ops (this
   branch added visible `toast.error` on import failure; EMPTY_DIRECTOR_TIMELINE
   over fake success).

## 5. What is lacking — prioritized

Severity: **P0** = blocks a professional team from adopting/keeping work;
**P1** = expected by serious users within weeks of using the tool;
**P2** = competitive depth / ecosystem.

### P0
1. **Timeline interchange (OTIO first, FCPXML second, EDL third).** Resolve
   imports/exports OTIO since v18; Avid/Media Composer 2026.8 improved OTIO
   round-trip; Kdenlive/Nuke/Olive read it too. Without it, every Resolve/
   Premiere-shop evaluation ends at "we can't ingest your footage pipeline."
   Deliverable: `packages/core/src/interchange/` — OTIO read+write for: tracks,
   clips, gaps, markers, transitions, speed, source ranges; FCPXML export for
   Final Cut; EDL CMX3600 for conform. ~2–3 weeks.
2. **Collaborative review (comments, timestamps, approval states) on exported
   cuts.** Frame.io is the bar; even a simple share-link + comment rail puts Kove
   in remote-team workflows. Resolve Studio and Premiere both have this; CapCut's
   shared spaces have it; Kove has nothing. 1–2 weeks with the existing share
   infra (`SharePage` already exists in `App.tsx`).
3. **Color management: at minimum HLG/PQ pass-through + a working space with
   proper tone mapping end-to-end.** Today `aces` hits are false positives
   ("faces"); no HDR path anywhere. Premiere/Resolve/Final Cut all ship HDR now.
   Even correct Rec.709 in/out with explicit matrix/transfer handling and a
   warning when HDR footage is misdetected would be a start. This is the silent
   correctness area: wrong gamma on export is invisible until a client complains.
4. **Resolve the `shader` effect path having no non-WebGPU fallback.** The golden
   `effect "shader" renders 0.00% of pixels` in SwiftShader proves it: on any
   machine without WebGPU, shader looks apply and produce *nothing* — the worst
   kind of silent breakage in an editor whose whole selling point is visible
   effects. Either fall back to a canvas2d approximation, refuse with
   `WEBGPU_REQUIRED` like `extract_segments` refuses un-analyzed footage, or at
   minimum surface a warning when the device is unavailable. (§7.3)

### P1
5. **Transcript-first surface in the default editor.** Kove has the pieces
   (transcript enrichment in the director, `ScriptViewDialog`, auto-caption,
   silence removal) but not a Descript-style "edit the text, cut the video" dock.
   Final Cut 12 shipped Transcript Search; Premiere has Text-Based Editing core.
   This is table stakes for talking-head, the highest-volume AI-edited genre.
   2 weeks, largely wiring existing transcript plumbing into the shell.
6. **Social publishing + direct upload** (YouTube at minimum; TikTok/Shorts via
   API where available). CapCut wins creators on "one click to published." Kove
   exports files and presets and stops. 1–2 weeks + OAuth verification.
7. **Stock/asset library** (even a free-tier Openverse/CC integration) to parity-
   check "start from nothing" moments; today import is local-only.
8. **Loudness meter in the UI** (BS.1770 measurement exists in the engine and the
   agent tool — surface it as a meter in the audio panel). Fairlight/Premiere both
   show integrated LUFS; Kove shows nothing.
9. **Proxy toggle UI + background proxy generation indicator.** The engine
   generates proxies (`media-import-service.generateProxy`) but there is no
   visible "working with proxies" state, no re-link affordance, no 4K confidence
   for weak machines.
10. **Version history UX.** Autosave + `HistoryPanel` exist but there is no
    named-version/branch model ("Final v3 for client"). Resolve/Premiere have
    proper versioning; Kove's is implicit.

### P2
11. **Plugin marketplace for fxpkg.** The format, validator, and compiler exist;
    there is no catalog, signing UX, or in-app browser. Ecosystems are the moat
    (OFX for Resolve, .mogrt for Premiere).
12. **AAF/XML for Avid** (after OTIO), plus round-trip fidelity docs.
13. **Team permissions / roles** on shared projects (once #2 lands).
14. **Motion DCI-P3/Rec.2020 previews**, ICC-aware preview.
15. **Relink media UX** (Premiere-grade "locate missing files") — today a missing
    blob is a dead end with a reconnect string, no guided flow.
16. **Keyboard-customizable command search** (searchable like ⌘K) — partially
    exists via `SearchModal`/`keyboard-shortcuts`; make bindings first-class.

### Explicit non-gaps (do not "fix")
- Magnetic timeline philosophy differences vs Premiere — Kove's clip/track model
  is fine; consistency within the app is what matters.
- Mobile-first editing — Kove is a desktop-browser editor; CapCut owns mobile.
- Generative video generation — out of scope by design (Kove edits footage).

## 6. Known-wrong "errors" root-caused this branch (why users saw so many)

The user-reported "SO MANY FUCKING ERRORS" were dominated by **harness and
dev-server defects**, not product bugs — with two genuine product bugs
discovered and fixed:

1. **`page.waitForFunction(async () => bool)` always returns immediately.**
   Proven empirically on this toolchain: an *async* predicate returning `false`
   (or `undefined`/`0`) still resolves the wait on first evaluation — Playwright
   accepts the resolved promise as success. This silently defeated every
   "wait for import to finish" gate in ad-hoc scripts and masked the send-before-
   import race. Serial `expect.poll(...).toBe(true)` is the correct pattern and
   is what the specs use.
2. **Vite (this sandbox's dev server) does not invalidate `packages/*` on file
   change** — pages kept stale transforms of `packages/agent/src/loop.ts` after
   edits; the failing-test diagnosis was impossible until the server was
   restarted and the staleness was independently confirmed via
   `curl /@fs/.../loop.ts` (old transform served while mtime had moved).
3. **Phantom project reads.** `initialProject` captured at turn start vs live
   store reads disagreed when the import landed mid-turn; combined with (1) this
   produced `hasSourceFootage=false` after an import the user could see.
   Not a product bug after all — a test-race amplifier (2) + (1). The director
   behaved *honestly* with what it saw.
4. **Genuine product bug fixed:** `tracksOf(project)` (undefined symbol) in
   `editor-context.ts` — `get_editor_state` would have thrown whenever the AI
   director read editor context; tsc caught it, fixed, 11/11 tests pass.
5. **Genuine product bug fixed:** failed media imports were **silently
   swallowed** in `AssetsPanel` (no toast, no console) — the direct reason
   "history stays coherent" hung with zero evidence for ~an hour. Now surfaces
   `toast.error("Import failed: <name>")`.
6. **Playwright `channel: "chrome"` / missing headless shell** — `effect-goldens`
   cannot launch a browser in this sandbox by default; the fix is a browser, not
   a code change. (Symlinked the @sparticuz binary; 62/63 goldens pass with it.)
7. **Tour backdrop swallows Send clicks intermittently** (`SpotlightTour`/
   `MoGraphTour`, `z-[100]` backdrop with `bg-black/80`). Flags are set in tests;
   cause of residual flakiness not fully disproven — Escape closes the tour.
   Filed here so it gets a root-cause in its own pass; do **not** paper over
   with `force: true`.
8. **localStorage flags / welcome-tour interference** across the whole suite — the
   E2E harness now sets `kove-advanced-onboarding-complete` + `mograph-tour-complete`
   everywhere deterministically.

## 7. Verification appendix

### 7.1 Director empty-timeline retry — the 90s-timeout failure, fully explained
Symptom: `expect(committed).toBe(true)` times out; page shows "AI request
failed"; turn ends with `EMPTY_DIRECTOR_TIMELINE`.
Root cause chain: the director (correctly!) refuses to plan a footage edit from
filename/duration guesses; the stub model had never called `extract_segments`,
so `plan_edit`'s frame-evidence gate (`ANALYSIS_REQUIRED`) rejected it, and the
loop rolled back. *The gate is the product working as designed.* The stub was
then scripted through the real path: text claim → (empty-timeline retry) →
`extract_segments` → `plan_edit` → applied → commit. Fixed in
`e2e/director-empty-timeline.spec.ts` (stub: text/extract/plan/final-text;
local-analyzer HTTP endpoint stubbed at `http://localhost:8000/analyze-frames`
with a sync VisionWorker-shaped payload; real frame capture runs in-page —
3 frames in 79 ms on the lavfi fixture).

### 7.2 Outer/inner call-count contract (what the test asserts and why)
`outerCalls` counts non-`submit_edit_plan` completions: 1 text claim →
2 `extract_segments` → 3 `plan_edit` → 4 nested `expand_prompt_result`
pre-step (answered with plain text; the helper falls back to question-based
expansion) → 5 final text. `expand_prompt_result` is structured-output-only —
**returning it as a tool call from the outer stub loops the turn into
`MAX_TOOL_CALLS` with an empty timeline** (verified empirically; documented in
the spec). Asserted: `outerCalls === 5`, `extractCalls === 1`,
`analysisBodies === 1`, 1 clip placed, `mediaId` matches source, committed.

### 7.3 `effect "shader"` golden — 0.00% pixels (open, product-relevant)
`packages/agent/src/eval/effect-goldens.test.ts` — the `shader` effect type
renders no pixels under SwiftShader/ANGLE. All other 62 goldens (effects,
transitions, baselines) pass. Either the WebGPU path silently no-ops when
`navigator.gpu` is unavailable, or the effect requires WebGPU unconditionally.
Action: route shader effects through the documented refusal pattern
(`WEBGPU_REQUIRED`) or a CPU fallback; add a skip-with-reason golden for
non-WebGPU environments. **Do not delete or loosen the golden.**

## 8. Recommended order of work

1. **P0 interchange (OTIO first)** — unlocks the pro pipeline; everything else
   is invisible to those users without it. (§5.1)
2. **P0 collaborative review MVP** — share link + timestamped comments + approval
   state; reuse `SharePage` plumbing. (§5.2)
3. **P0 shader/WEBGPU_REQUIRED + fallback** — small, high trust. (§5.4 / §7.3)
4. **P0 HDR/CM scoping document + Rec.709 matrix correctness** — even a
   "refuse unknown color space with a warning" pass buys trust. (§5.3)
5. **P1 transcript-first dock** — the #1 AI-editor genre (talking-head) is won
   or lost here; Kove has 80% of the plumbing. (§5.5)
6. Publish/share, stock, loudness meter UI, proxy UI, version history (P1s) —
   schedule as they become the top user complaints.
